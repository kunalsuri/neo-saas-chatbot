🤖 Neo SaaS Chatbot Platform

Quick setup guide to run code and execute tests.

1. Install & Configure

Install Node Modules
npm install
Configure Environments (Creates .env file)
Windows 
npm run setup:windows
macOS / Linux 
npm run setup:local

2. Run Application

Start Dev Server (Both API and SPA client on localhost:5000)
npm run dev
Build for Production
npm run build

3. Run Tests

Run All Test Suites (Client + Backend)
npm test
Run Extended Backend Suite Only
npm run test:extended
Run Coverage Report
npm run test:all
