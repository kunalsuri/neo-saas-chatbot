# Security Policy

We take security issues seriously and are committed to ensuring the safety of this project. Thank you for helping to keep our project secure.

## Supported Versions

Currently, the following versions of the project receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| v1.x.x  | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please report it privately:
1. Contact the project maintainer by sending an email/message or through private vulnerability reporting channels on GitHub.
2. Provide a detailed description of the issue, including steps to reproduce, the impact, and any potential fixes.

We will acknowledge receipt of your report within 48 hours and work with you to resolve the issue as quickly as possible. We request that you give us reasonable time to fix the issue before making it public.
